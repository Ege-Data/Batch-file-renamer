# Batch-file-renamer
A fast, lightweight 64-bit C++ batch file renaming utility for Windows with Dark Mode and multi-language support.
🛡️ Security & VirusTotal Scan

This project is 100% open-source and safe.

68/71 major antivirus engines pass the file as completely clean.

A few ML/Heuristic detectors (e.g., CrowdStrike ML) may flag a false positive due to the lack of an expensive code-signing certificate and batch file renaming behavior.

You can inspect the full source code (main.cpp) yourself or compile it from scratch using Visual Studio / MinGW.
